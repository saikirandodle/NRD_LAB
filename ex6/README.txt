BOOKSTORE XML VALIDATION

Files:
1. bookstore-dtd.xml  - XML file for DTD validation
2. bookstore.dtd       - DTD schema
3. bookstore-xsd.xml   - XML file for XSD validation
4. bookstore.xsd       - XSD schema

Keep all four files in the same folder.

DTD validation:
    python validate_dtd.py

XSD validation:
    python validate_xsd.py

Install lxml first:
    pip install lxml
