# NRD Lab

A comprehensive collection of **NRD Experiments** covering frontend development, Java, databases, XML, Servlets, session management, Node.js, Express.js, REST APIs, JWT authentication, React.js, Chart.js, and deployment using GitHub.

## 📚 List of Experiments

### 1. Responsive Shopping Cart using CSS3

Build a responsive shopping cart web application with:

* User Registration
* User Login
* Product Catalog
* Shopping Cart
* CSS3
* Flexbox
* CSS Grid
* Responsive Web Design

**Technologies:** HTML5, CSS3, Flexbox, CSS Grid

# 📊 Learning Outcomes

After completing these experiments, students will be able to:

* Develop responsive web applications using HTML and CSS.
* Use Flexbox, CSS Grid, and Bootstrap for responsive design.
* Implement client-side form validation using JavaScript.
* Use modern ES6 JavaScript features.
* Consume REST APIs and display API data graphically.
* Connect Java applications to relational databases using JDBC.
* Perform CRUD operations on databases.
* Create and validate XML documents using DTD and XSD.
* Develop web applications using Java Servlets.
* Implement session tracking using Cookies and HTTP Sessions.
* Build custom servers using Node.js.
* Work with Node.js core modules.
* Develop REST APIs using Express.js.
* Test APIs using Postman.
* Implement JWT-based authentication and authorization.
* Develop component-based applications using React.
* Implement routing in React applications.
* Integrate external APIs with React.
* Create graphical data visualizations using Chart.js.
* Use Git and GitHub for version control and deployment.
